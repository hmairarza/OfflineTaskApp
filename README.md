
# OfflineTaskApp

## Deskripsi
OfflineTaskApp adalah aplikasi pengelola tugas berbasis Android yang memungkinkan pengguna mencatat dan mengelola tugas tanpa memerlukan koneksi internet.

## Fitur
- Menambahkan tugas
- Melihat daftar tugas
- Melihat detail tugas
- Mengedit tugas
- Mengelola status tugas
- Menyimpan data secara lokal menggunakan Room Database

## Teknologi
- Kotlin
- Android Studio
- Jetpack Compose
- Room Database

## Cara Menjalankan
1. Clone atau download repository ini.
2. Buka proyek menggunakan Android Studio.
3. Tunggu proses Gradle Sync selesai.
4. Jalankan aplikasi menggunakan emulator atau perangkat Android.
